# CrowPanel local web/API dashboard

See the project-root README for current setup, USB/Wi-Fi transport, image/chart APIs, weather/ticker configuration, Docker operation and validation. Run `bash scripts/web.sh` from the project root, then open http://127.0.0.1:8787 .

This server uses the existing sender CLI, which must be rebuilt when upgrading to Wi-Fi support. The firmware needs one USB flash for Wi-Fi operation; USB-only operation works with the original firmware.
